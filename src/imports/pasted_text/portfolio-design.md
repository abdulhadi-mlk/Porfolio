# Animation Requirements

Animations are important, but they should feel **professional rather than distracting**.

Use:

* Smooth page transitions
* Scroll reveal animations
* Fade + slide animations
* Staggered card animations
* Hover effects
* Magnetic buttons
* Project card tilt
* Animated gradient background
* Floating particles/nodes
* Animated skill cards
* Timeline animation
* Smooth navigation scrolling
* Text reveal animation
* Subtle cursor interaction
* Image parallax
* Number counter animation

Animation principle:

**"Everything should move with purpose."**

Avoid excessive bouncing, spinning, or flashy effects.

Animations should also respect **prefers-reduced-motion** for accessibility.

Use a sophisticated dark theme.

Base:

* Deep charcoal / near-black background
* Slightly lighter cards
* White/off-white primary text
* Muted gray secondary text

Accent:

Use a combination of **electric blue / cyan / violet** very subtly to communicate AI/technology.

The accent colors should primarily appear in:

* Buttons
* Highlights
* Gradients
* Icons
* Hover states
